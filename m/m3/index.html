写作实战——高频职场写作

模块三 · 约3—4小时
学习目标：覆盖职场中最高频的写作类型，掌握“人做决策与核验，AI做初稿与优化”的协同写法。
3.1 日常沟通类：邮件、即时消息、工作日志3.2 汇报与总结类：周报、月报、项目进展、年度总结3.3 商业与传播类：从“写对”到“打动人”3.4 贯穿原则：最后一步永远是核验小测验实践任务

3.1日常沟通类：邮件、即时消息、工作日志

日常沟通写作的关键是收件人意识：同一件事，发给上级、平级和客户，提示词里的角色、语气和详略要求截然不同。

四类常见邮件的要点

类型必须写清提示词里可以加的限制
通知什么事、何时、何地、谁参加、要做什么“要点用编号列出，便于对方快速扫读”
请求请对方做什么、为什么需要他、截止时间、能提供什么支持“开头一句话说明请求，不要寒暄过长”
跟进上次沟通的结论、当前进展、需要对方回应的事项“语气友好，不要显得在催促或指责”
致歉发生了什么、影响、原因、补救措施、预防措施“承担应承担的责任，不推卸、不过度承诺”
即时消息和工作日志即时消息要短，可以要求“改成3行以内、适合微信/企业IM发送的版本”；工作日志可以把零散记录丢给AI，要求“按项目归类，每条一句话，保留原始数据”。

3.2汇报与总结类：周报、月报、项目进展、年度总结

核心方法是结构化投喂：先把素材整理成清单，再让AI按固定逻辑成文。AI负责“写成文”，内容本身必须来自你。

① 整理素材清单→② 选择成文逻辑→③ 加信息边界限制→④ 生成并核对数据

3.3商业与传播类：从“写对”到“打动人”

产品介绍、活动文案、社交媒体内容、汇报PPT讲稿，侧重点转向传播目标。提示词里要回答：给谁看？希望他/她看完做什么（报名、购买、转发、记住一个观点）？

用风格指令控制语气。下面是同一条产品信息在四种风格下的写法（示意）：

汇报PPT的讲稿框架

你是一名擅长汇报的部门负责人。我将在{{场合}}上向{{听众}}做{{时长}}分钟汇报，主题是{{主题}}。
以下是每页PPT的要点：
{{逐页要点}}
请为每一页写一段讲稿：开头一句点明本页结论，中间用1-2个事实支撑，结尾一句过渡到下一页。
要求：口语化但不随意；每页讲稿控制在{{每页字数}}字左右；不要添加我没有提供的数据。

3.4贯穿原则：最后一步永远是核验

不论写的是一条微信还是一份对外邮件，最后一步都是事实核验与口径校对：

  • 数据准不准：每个数字、日期、金额、人名、机构名都和原始材料对一遍。
  • 结论有没有依据：AI加的“显著提升”“全面完成”有没有事实撑腰？
  • 表述有没有越权或失当：是否替领导做了承诺、对外泄露了内部信息、使用了不该用的口径？

小测验

启用 JavaScript 后可作答并查看解析。下面是题目预览。

  1. 同一件“项目延期”的事，发给客户的邮件和发给上级的邮件，提示词中最需要调整的是？
    • 只需要改称呼
    • 角色、语气与详略
    • 字体和格式
    • 不需要调整
  2. 写周报时，下列哪种做法最容易“翻车”？
    • 先把事项和数据整理成清单再交给AI
    • 要求AI按“成果—问题—计划”成文
    • 只告诉AI“我是做运营的，帮我写本周周报”
    • 要求缺失信息标注【待补充】
  3. 关于AI生成的文案，下列哪一步不能省略？
    • 让AI再润色一遍
    • 换一种风格再生成
    • 事实核验与口径校对
    • 增加字数
实践任务

用一份真实工作材料走完全流程

选取一份你真实的工作材料，比如近期周报或一份待起草的通知。先脱敏：人名、客户名、金额等换成代号。然后完成下面四步，并标注哪些内容来自AI、哪些由你改写、为什么改。

结构化素材整理→提示词设计→初稿生成→人工修订定稿
  1. 把素材整理成清单（事项 / 数据 / 问题 / 计划，或这项任务所需的要素）。
  2. 按五要素写提示词，加上信息边界限制。
  3. 生成初稿。
  4. 逐段修订，并在下表中记录修改情况。
  5. 用输出核验助手检查定稿。
