5.1输出核验的三道关口

① 事实核验→② 逻辑核验→③ 合规核验
关口查什么典型问题
事实数据、日期、引文、专有名词、人名职务、机构名称是否准确AI把“同比增长8%”写成“18%”；引用了一份不存在的文件；把部门名称写错
逻辑因果关系是否成立；结论是否有跳跃；前后是否矛盾“由于开展了培训，客户满意度提升了”，但两者之间没有证据；前文说延期一周，后文说两周
合规是否涉及未公开信息；是否触碰保密、个人信息与版权边界；是否越权表态对外邮件里出现了内部定价；直接使用来源不明的图片；替公司做出赔偿承诺

顺序有讲究：先确认事实，再看推理，最后看能不能发。事实错了，后两关都没有意义。

5.2AI办公中的红线意识

红线一：不将敏感数据输入未经批准的外部工具包括涉密信息、未公开的经营数据、客户资料、员工个人信息等。
红线二：AI生成内容在正式对外使用前，须经责任人审核对外发布的文案、发给客户的邮件，都要有人审核、有人署名负责。
红线三：人事、法务、财务类文书不得以AI输出直接定稿劳动合同、处分决定、法律函件、财务报告等直接影响他人权益或单位责任，AI只能辅助起草和检查，必须由专业人员审定。

5.3搭建你的个人AI办公模板包

把本课程中验证有效的东西整合起来，形成一套随时可调用的工具，就会形成“越用越顺手”的正循环：

提示词模板

通知、周报、邮件、汇报、纪要……每类1-2条，标注适用场景和注意事项。

素材结构

周报素材清单、会议纪要表格、PPT大纲结构等。

核验清单

三道关口清单，以及你所在岗位特有的检查项（如财务口径、对外表述）。

放在哪里

  • 一份文档：在笔记软件或团队文档中按场景分类，最简单。
  • 快捷短语：把最常用的几条设成输入法自定义短语或系统文本替换，打几个字母就能调出。
  • 工具内置功能：一些AI工具支持保存常用指令或自定义助手，可以把固定的角色和要求放进去。
保持更新每次发现一条提示词“改了某处就好用多了”，就顺手更新模板，并记下修改原因。

小测验

启用 JavaScript 后可作答并查看解析。下面是题目预览。

  1. 三道关口的推荐顺序是？
    • 合规 → 逻辑 → 事实
    • 事实 → 逻辑 → 合规
    • 逻辑 → 事实 → 合规
    • 只做合规核验即可
  2. AI写的总结中说“由于本季度开展了三次培训，员工流失率显著下降”。这首先属于哪类需要核验的问题？
    • 格式问题
    • 逻辑核验：因果关系是否有依据
    • 版权问题
    • 字数问题
  3. 以下哪项可以由AI起草初稿、经本人审核后使用？
    • 员工处分决定的最终文本
    • 内部培训活动的报名通知
    • 与客户签署的合同条款定稿
    • 年度财务报告定稿
实践任务

为你的岗位划一条“AI分界线”

结合你的岗位，列出3项“可以放心交给AI做初稿”的任务，和3项“AI只能辅助、不可替代人判断”的任务，并说明分界依据。

可以参考的分界依据是否需要事实判断或价值取舍？出错的后果有多大、能否挽回？是否涉及敏感数据或他人权益？是否需要有人署名负责？
