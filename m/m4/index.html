会议、数据与视觉表达

模块四 · 约2—2.5小时
学习目标：把AI从“写作工具”扩展为“办公流程节点”，覆盖文字之外的常见产出形式。
4.1 会议全流程AI辅助4.2 数据整理与初步分析4.3 PPT与视觉材料：大纲先行、内容校验、视觉后置小测验

4.1会议全流程AI辅助

会前

  • 议程生成：给出会议目的、参会人、时长，让AI排出带时间分配的议程。
  • 材料预读摘要：把会议材料交给AI，生成“一页纸摘要 + 需要在会上决定的问题”。

会中

  • 录音转写：使用会议软件自带或单位允许的转写工具。
  • 发言人区分：自动区分的结果常有错位，需要人工校正关键发言。
  • 录音前应告知参会者，涉密会议不录音、不上传。

会后

  • 纪要提炼：决议、待办、责任人、时限。
  • 跟进邮件：基于纪要生成，发给参会人和相关方。
  • 纪要发出前由会议主持人或记录人确认。

纪要提炼提示词

你是一名严谨的会议记录员。下面是一段会议转写文本。
请提炼会议纪要，输出四部分：
1. 会议基本信息（主题、时间、参会人，文本中没有的标注【待补充】）；
2. 决议事项（只写会上明确达成一致的结论）；
3. 待办事项表格：事项 / 责任人 / 截止时间（没有明确责任人或时间的，标注【未明确】，不要推测）；
4. 尚未达成一致、需后续讨论的问题。
要求：忠于原文，不添加原文没有的信息；口语化表达改为书面语。
转写文本：
……
为什么强调“不要推测”转写文本里常有“这个小王跟一下吧”“尽快”这类模糊表达。AI很可能把它写成“王××负责，本周五前完成”，看起来很完整，却可能是错的。宁可标【未明确】，再由人去确认。

4.2数据整理与初步分析

用自然语言就能指挥AI完成很多表格工作：清洗（去重、格式统一、字段拆分）、分类汇总、生成图表。很多对话工具支持上传表格并运行代码来处理，也可以让AI写出 Excel/WPS 公式供你自己使用。

AI在数据分析中的边界

擅长：执行和描述“按部门统计人数”“找出环比下降超过10%的品类”“描述一下这张图的趋势”。
不擅长：判断业务含义“为什么下降”“该不该砍掉这个品类”。AI能列出可能原因供你参考，但判断要靠你掌握的业务事实。
数据脱敏与合规底线上传前删除或替换姓名、手机号、身份证号、银行账号、薪资等个人信息与敏感字段；客户数据、财务数据未经批准不得上传外部工具。AI算出来的汇总数，要抽查几行原始数据核对。

4.3PPT与视觉材料：大纲先行、内容校验、视觉后置

① 大纲先行：AI生成汇报结构与逐页要点→② 内容校验：人确认每页结论与数据→③ 视觉后置：进入PPT工具排版、配图

很多AI工具能“一键生成PPT”，页面很漂亮，但内容常常是泛泛而谈、数据缺失，甚至是编的。如果先花时间调排版，再发现内容不对，就全白费了。所以顺序很重要。

你是一名擅长结构化表达的咨询顾问。
我需要向{{听众}}汇报{{主题}}，时长{{时长}}分钟，核心结论是：{{核心结论}}。
素材如下：
{{素材}}
请输出一份{{页数}}页左右的PPT大纲，每页包含：页面标题（用一句话写出本页结论）、3条以内要点、建议的图表类型。
要求：采用“结论先行”结构；只使用我提供的素材，缺少支撑数据的页面标注【需补充数据】。
三个问题每页标题是不是一个明确的结论？每个结论有没有数据或事实支撑？删掉这一页，汇报会不会缺东西？

小测验

启用 JavaScript 后可作答并查看解析。下面是题目预览。

  1. 下列哪项属于AI在数据分析中“不擅长”的事？
    • 按部门汇总人数
    • 统一日期格式
    • 判断某产品是否应该下架
    • 描述图表趋势
  2. 使用AI做PPT的推荐顺序是？
    • 先选模板 → 再写内容 → 最后核对
    • 大纲先行 → 内容校验 → 视觉后置
    • 一键生成 → 直接汇报
    • 先配图 → 再写标题
  3. 把员工满意度调查表交给外部AI工具分析前，首先应该？
    • 删除或替换姓名、工号等个人信息，并确认工具是否获准使用
    • 把表格转成PDF
    • 把所有数据复制到对话框
    • 先让AI猜结论
