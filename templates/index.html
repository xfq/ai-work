提示词模板库

每条模板都按「角色 + 背景 + 任务 + 要求 + 格式」组织。共 17 条，覆盖通知、邮件、周报、汇报、会议纪要、数据与PPT等场景。

启用 JavaScript 后可按关键词搜索、按分类筛选，并在页面上填写变量、一键复制。

通知 · 专家型
项目延期通知
项目无法按期交付，需要通知客户或协作方。
通知 · 专家型
会议/活动通知
内部会议、培训、活动的通知。
周报与汇报 · 专家型
周报（成果—问题—计划）
把零散的工作记录整理成一份周报。
周报与汇报 · 专家型
结论先行的项目进展报告
向领导汇报项目整体情况，领导时间有限。
周报与汇报 · 迭代型
年度总结提纲
先搭年度总结的框架，再逐节填充。
邮件 · 专家型
请求协助邮件
请其他部门或同事帮忙。
邮件 · 专家型
跟进邮件
对方迟迟没有回复，需要礼貌跟进。
邮件 · 专家型
致歉邮件
工作失误导致对方受到影响。
会议 · 专家型
会议议程生成
会前快速排出一份有时间分配的议程。
会议 · 专家型
会议纪要提炼
把转写文本变成结构化纪要。
会议 · 专家型
会后跟进邮件
基于纪要通知参会人和相关方。
数据 · 专家型
表格清洗指令
让AI清洗一张格式混乱的表格。
数据 · 专家型
数据描述（不做业务判断）
让AI客观描述数据变化，作为你分析的起点。
PPT · 专家型
汇报PPT大纲（结论先行）
先做内容，再做排版。
PPT · 专家型
逐页讲稿
PPT做好了，需要配一份讲稿。
传播 · 示范型
活动文案（多风格对比）
同一个活动，生成不同风格的文案供挑选。
核验 · 迭代型
让AI自查初稿
在人工核验前，先让AI自己找一遍问题。
